# Round 28c: All Waters Are One sits directly under a spoils focus (13,36), so its icon is OWB's GFX_goal_LNS_texan_dollar
# (94x77, the Texan dollar - the Union's ledgers the clerks keep) in place of GFX_goal_CHC_Texas (149x154).

# Merged away in round 27 (their distinctive effects live on in the kept focus named):
#   The Silent Partner               -> mltd_tex_all_waters_are_one (token_army + civilian intel on each Texan

#                                       mltd_tla_iron_bones_theft_tt - a quarter of each store since round 28b, paid to us
#                                       as mirelurks since round 28c - 20 army experience, +100 caps)

# Rules every story focus follows (SPEC round 27): no intelligence gate in any `available`; every bead is takeable
# once its target is gone (or our subject) and then pays a political-power fallback; cancel_if_invalid = no and
# continue_if_invalid = yes; heads and beads ai_will_do 3, chapter and close 10; the war capstones keep their
# readiness gate for an AI (a human is never gated) - Black Water and The Drowned God dropped their Legion term, which
# the chapter already enforces, as Act V's wars dropped the NCR's - and The Serpent Drowns, a war no close depends on,
# keeps its stage (mltd_ai_stage_ate) and also waits for a safe target and for the Texan war to be over. Since the
# round-27 review each war's AI hold sits in its `available` (mltd_ai_may_start_<texas|ate|tla>_war, hidden and AI-only),
# not in ai_will_do: an AI takes any listed focus that is available, whatever its ai_will_do reads. Each also waits while
# MLT is losing a war, and The Drowned God Sleeps, optional like The Serpent Drowns, for every target it would declare on
# to be a safe target.
#
# Round 28b (the play-test fixes):
# - The two wars' thefts are a quarter of what each victim holds in store, not a flat 300-800 rifles: the plan opens this act
#   in 2284 with ~90-110 military factories (CONQUEST_PLAN.txt's 2285-12 snapshot) and an army of mirelurks, where 800
#   rifles is under 3 % of a year's arms output and of little use; a quarter of the enemy's reserve on the war's first day
#   weighs the same in any year. Each share is read into a temp variable for the preview (the tooltip prints it) and again
#   at completion; the transfers are hidden. The quarter is a literal in each focus and in its tooltip - change both.
# - Round 28c: the thefts pay in what the tribe fields, as in Act V. The victims still lose their stores (no producer on
#   the removal), but rifles are no use to an army of mirelurks, so the haul is melted down into harness and shell-plate
#   for the brood: one mirelurk (the archetype amphibious_beast_equipment, our best unlocked breed) for every five pieces
#   taken, about their worth in IC. The five is a literal in each focus and in its tooltip - change both.
# - Black Water Rising's +3 energy in the capital (a flat resource that MLT's creature army never burns) is gone, with
#   nothing in its place: its 180-day idea, mltd_tex_black_water (common/ideas/mltd_ideas.txt), already pays in modifiers
#   that scale (+5 % factory output, +5 % construction speed), and its theft now pays hundreds of mirelurks where it paid
#   800 rifles. (Round 28c's build first added a -10 % creature build cost to the idea; the review dropped it, because it
#   stacked with Feed the Spawning Pools and mltd.51 b's Emptied Pens, both running then, into a third copy of the same cut.)
# - Round 28c (the review): Black Water Rising's old fallback, +30 political power, is now a floor, paid whenever the haul
#   comes to fewer than 30 mirelurks (the rate is in mltd_act5_focus.txt's header), so a small store never pays less than
#   an empty one. The Drowned God Sleeps has no fallback: its +100 caps and 20 army experience come either way.
# - Every effect that hangs on a condition that can still change while the focus runs (the Speaker's rule, the Aztlan navy,
#   Tlaloc's draining memory) is previewed as a condition, with its native lines (effect_tooltip), and applied in
#   hidden_effect, so the tooltip is true whichever way it falls; a condition that can no longer change shows as it is.
#
# Reading the long rewards: where a completion_reward renders more than about six lines, the house spacer
# (custom_effect_tooltip = mltd_newline_tt, loc " \n", as in the rituals and R'lyeh Rises) breaks it into blocks in the tree's
# usual order - what M'lyeh gains, what the target loses, the intelligence, the declaration - so the preview reads as two to
# four short paragraphs instead of one wall. The spacers are presentation only: no number, gate, effect or order changed, and
# each sits inside the branch it belongs to, never as a branch's last line. All Waters Are One, Black Water Rising, The
# Feathered Tide, The Iron God Dreams and The Drowned God Sleeps carry them; the chapter, The Serpent Drowns and the close are
# short enough to read as they stand.
#
# 2026-09-24 (the user: war focuses should bring bonuses against the country and an immediate buff, not stability and
# war-support losses of little consequence; and too much text): each of the three wars declares, then - against a target that
# is not MLT's subject - grants its 180-day idea with +10 % attack and defence against its targets (mltd_tex_black_water,
# mltd_ate_the_serpent_hunted, mltd_tla_dreams_of_wire) and the shared 60-day mltd_the_first_wave (+10 % division recovery
# rate, +5 % breakthrough), and takes its theft, one line with no floor. Gone: the targets' stability and war-support losses,
# Black Water's 30 and The Serpent Drowns' 40 army experience, the Frogs' navy experience, The Drowned God Sleeps' 20 army
# experience and 100 caps. The drain on Tlaloc's databanks and the stolen tech stay. The Feathered Tide lost the Speaker's dream.

# Texas: the Order's pilgrims and clerks work their way into the Texan counting-houses (Silent Partner merged in)
shared_focus = {
	id = mltd_tex_all_waters_are_one
	icon = GFX_goal_LNS_texan_dollar	# round 28c: a normal-height icon (see the header) - a spoils focus sits directly above
	prerequisite = { focus = mltd_the_southern_deep }
	x = -2
	y = 1
	relative_position_id = mltd_the_southern_deep
	cost = 30
	ai_will_do = { factor = 3 }
	# 2026-09-23: bypassed once TBH and LNS are all gone - with its nation gone it paid only its fallback
	bypass = {
		NOT = { country_exists = TBH }
		NOT = { country_exists = LNS }
	}
	cancel_if_invalid = no
	continue_if_invalid = yes
	completion_reward = {
		mltd_intel_foothold = yes
		if = {
			limit = {
				OR = {
					country_exists = TBH
					country_exists = LNS
				}
			}
			# round 17: the cults of M'lyeh in this branch's countries wither half as fast (mltd_cult_refresh)
			custom_effect_tooltip = mltd_tex_cult_sheltered_tt
			hidden_effect = {
				if = {
					limit = { country_exists = TBH }
					TBH = { set_country_flag = mltd_cult_sheltered }
				}
				if = {
					limit = { country_exists = LNS }
					LNS = { set_country_flag = mltd_cult_sheltered }
				}
			}
			# All Waters' intel and The Silent Partner's, one grant per tag: civilian 15 (Silent Partner's), army 10
			# (All Waters'), and The Silent Partner's army token
			if = {
				limit = { has_dlc = "La Resistance" }
				if = {
					limit = { country_exists = TBH }
					add_intel = {
						target = TBH
						civilian_intel = 15
						army_intel = 10
					}
					add_operation_token = { tag = TBH token = token_army }
				}
				if = {
					limit = { country_exists = LNS }
					add_intel = {
						target = LNS
						civilian_intel = 15
						army_intel = 10
					}
					add_operation_token = { tag = LNS token = token_army }
				}
			}
			else = {
				# All Waters' +25 and The Silent Partner's +25
				add_political_power = 50
			}
			custom_effect_tooltip = mltd_newline_tt
			if = {
				limit = { country_exists = TBH }
				TBH = {
					add_stability = -0.04
					add_political_power = -25
				}
			}
			if = {
				limit = { country_exists = LNS }
				LNS = {
					add_stability = -0.04
					add_political_power = -25
				}
			}
		}
		else = {
			custom_effect_tooltip = mltd_tex_texas_gone_tt
			add_political_power = 50
		}
		custom_effect_tooltip = mltd_newline_tt
		# The Silent Partner's skim from the Union's ledgers
		set_temp_variable = { caps_to_add = 80 }
		add_caps = yes
	}
}

# the war on Texas (Wreckers on the Trinity merged in)
shared_focus = {
	id = mltd_tex_black_water_rising
	icon = GFX_goal_ACH_texico_rig
	prerequisite = { focus = mltd_tex_all_waters_are_one }
	x = -2
	y = 2
	relative_position_id = mltd_the_southern_deep
	cost = 30
	will_lead_to_war_with = TBH
	will_lead_to_war_with = LNS
	ai_will_do = { factor = 3 }
	available = {
		custom_trigger_tooltip = {
			tooltip = mltd_tex_one_master_tt
			OR = {
				has_global_flag = texas_formed
				NOT = { country_exists = TBH }
				NOT = { country_exists = LNS }
				date > 2280.1.1
			}
		}
		# round 22: the focus is the declaration, so an AI takes it only when the army is ready - only while it would start a
		# war. Round 27: its stage term (mltd_ai_legion_beaten) is gone, as on Act V's wars - the chapter already needs Act V's
		# close, which asks the same thing, so the term only waited on an earlier act (spec rule 7). Since the round-27 review
		# the hold sits here, hidden and AI-only, because an AI takes any listed focus that is available whatever its
		# ai_will_do reads; it also waits while MLT is losing a war (mltd_ai_triggers.txt, section W)
		mltd_ai_may_start_texas_war = yes
	}
	# 2026-09-23: bypassed once TBH and LNS are all gone - with its nation gone it paid only its fallback
	bypass = {
		NOT = { country_exists = TBH }
		NOT = { country_exists = LNS }
	}
	cancel_if_invalid = no
	continue_if_invalid = yes
	completion_reward = {
		if = {
			limit = {
				country_exists = TBH
				NOT = { has_war_with = TBH }
				TBH = { NOT = { is_subject_of = ROOT } }
			}
			declare_war_on = {
				type = annex_everything
				target = TBH
			}
		}
		if = {
			limit = {
				country_exists = LNS
				NOT = { has_war_with = LNS }
				LNS = { NOT = { is_subject_of = ROOT } }
			}
			declare_war_on = {
				type = annex_everything
				target = LNS
			}
		}
		# 2026-09-24 (the user: war focuses should bring bonuses against the country and an immediate buff, not stability and
		# war-support losses of little consequence; and less text): the war, then - against a target that is not MLT's subject -
		# the 180-day idea with +10 % attack and defence against it, The First Wave (60 days) and the theft, one line; with the
		# target MLT's subject, +50 political power. The side branches keyed to the target's own story went with the losses
		# (each Texan tag's -6 % stability and -3 % war support, the robbed tag's -2 % war support and the 30 army experience,
		# round 28b-2026-09-23). Wreckers on the Trinity (merged): a quarter of each Texan tag's rifles, each store of at
		# least 100, summed and paid as one mirelurk for every five; the quarter and the five are literals here and in
		# mltd_tex_wreckers_theft_tt. Its political-power floor went with the rest. The intelligence stays, native
		if = {
			limit = {
				OR = {
					AND = {
						country_exists = TBH
						TBH = { NOT = { is_subject_of = ROOT } }
					}
					AND = {
						country_exists = LNS
						LNS = { NOT = { is_subject_of = ROOT } }
					}
				}
			}
			add_timed_idea = {
				idea = mltd_tex_black_water
				days = 180
			}
			add_timed_idea = {
				idea = mltd_the_first_wave
				days = 60
			}
			set_temp_variable = { mltd_theft_tbh = 0 }
			set_temp_variable = { mltd_theft_lns = 0 }
			if = {
				limit = {
					country_exists = TBH
					TBH = { NOT = { is_subject_of = ROOT } }
					TBH = { has_equipment = { infantry_equipment > 99 } }
				}
				set_temp_variable = { mltd_theft_tbh = TBH.num_equipment@infantry_equipment }
				multiply_temp_variable = { mltd_theft_tbh = 0.25 }
				round_temp_variable = mltd_theft_tbh
			}
			if = {
				limit = {
					country_exists = LNS
					LNS = { NOT = { is_subject_of = ROOT } }
					LNS = { has_equipment = { infantry_equipment > 99 } }
				}
				set_temp_variable = { mltd_theft_lns = LNS.num_equipment@infantry_equipment }
				multiply_temp_variable = { mltd_theft_lns = 0.25 }
				round_temp_variable = mltd_theft_lns
			}
			set_temp_variable = { mltd_theft_brood = mltd_theft_tbh }
			add_to_temp_variable = { mltd_theft_brood = mltd_theft_lns }
			divide_temp_variable = { mltd_theft_brood = 5 }
			round_temp_variable = mltd_theft_brood
			custom_effect_tooltip = mltd_tex_wreckers_theft_tt
			hidden_effect = {
				if = {
					limit = { check_variable = { mltd_theft_tbh > 0 } }
					set_temp_variable = { mltd_theft_negative = mltd_theft_tbh }
					multiply_temp_variable = { mltd_theft_negative = -1 }
					TBH = {
						add_equipment_to_stockpile = {
							type = infantry_equipment
							amount = mltd_theft_negative
						}
					}
				}
				if = {
					limit = { check_variable = { mltd_theft_lns > 0 } }
					set_temp_variable = { mltd_theft_negative = mltd_theft_lns }
					multiply_temp_variable = { mltd_theft_negative = -1 }
					LNS = {
						add_equipment_to_stockpile = {
							type = infantry_equipment
							amount = mltd_theft_negative
						}
					}
				}
				if = {
					limit = { check_variable = { mltd_theft_brood > 0 } }
					add_equipment_to_stockpile = {
						type = amphibious_beast_equipment
						amount = mltd_theft_brood
					}
				}
			}
		}
		else = { add_political_power = 50 }
		if = {
			limit = { has_dlc = "La Resistance" }
			if = {
				limit = { country_exists = TBH }
				add_intel = {
					target = TBH
					civilian_intel = 20
					army_intel = 20
				}
			}
			if = {
				limit = { country_exists = LNS }
				add_intel = {
					target = LNS
					civilian_intel = 20
					army_intel = 20
				}
			}
		}
	}
}

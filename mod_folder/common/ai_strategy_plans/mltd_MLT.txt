# Rising Tide - MLT AI strategy plans
#
# Three phase plans for an AI Mirelurk Tribe, in the order of CONQUEST_PLAN.txt: the Oregon opening until
# mlt_kingdom_of_mlyeh, the Kingdom and the Books until mltd_the_final_ritual, then the late game. Their enable
# and abort blocks are mutually exclusive, so one focus list runs at a time, and all three stop while MLT is a
# subject. A plan ends only through abort (an enable that turns false does not end it), so each abort is the
# next plan's enable; plans take no abort_when_not_enabled, which no vanilla or OWB plan uses.
#
# ai_national_focuses is taken in order, the first available entry first; unavailable entries are skipped, so
# the fillers at the end run while a conquest, egg, Book or population gate holds everything above them (OWB
# does the same at BDT.txt:43). A listed focus that is available is taken whatever its ai_will_do reads: run 8
# (ai_runs/20260918-170847) completed The Tide-Wall and The Turbines Sing while their ai_will_do read 0. So every
# story war focus holds an AI in its own `available` (hidden, AI-only: common/scripted_triggers/mltd_ai_triggers.txt,
# section W). focus_factors scales ai_will_do, which the AI consults once no listed focus is available; whether a
# focus_factors 0 holds a listed focus is untested - run 8's two Muttfruit FOCUS lines were bypasses (owning 186,
# and 493 and 450), which the telemetry records as completed, not the AI's choice.
# research weights technology categories (common/technology_tags); ideas weights advisors by idea_token
# (common/characters/MLT.txt; OWB precedent BOS.txt:58-60).

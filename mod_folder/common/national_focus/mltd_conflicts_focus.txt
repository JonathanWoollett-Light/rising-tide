# Rising Tide (MLT) - conflict sub-trees.
# Shared focuses, pulled into mlt_nf by one `shared_focus = <root>` line each in
# "Mirelurk Tribe (MLT) Focus.txt". Each root opens after mlt_kingdom_of_mlyeh via `available`,
# has absolute x/y and no prerequisite; every other focus hangs off its own root, so the engine
# pulls it in through that prerequisite (a shared focus whose only prerequisite is a national
# focus would not appear). Layout: CLAUDE.md > Conflict sub-trees.
